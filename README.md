# ELMAQ Engenharia — Site Institucional

Site institucional da ELMAQ Engenharia e Máquinas, preparado para publicação web.

## Estrutura
- `index.html` — conteúdo principal
- `styles.css` — identidade visual e responsividade
- `script.js` — interações leves
- `vercel.json` — configuração de publicação

## Publicação
A versão de preparação está na branch `site-inicial`. Após revisão, ela pode ser integrada à branch `main` e conectada a uma plataforma de hospedagem.

## Observação sobre imagens
Nesta primeira versão, algumas imagens são carregadas do endereço público atual da ELMAQ. Em uma etapa posterior, recomenda-se armazenar cópias próprias dos arquivos de mídia dentro do projeto para eliminar dependência do endereço antigo.
